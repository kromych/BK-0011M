# Original BK documentation

Soviet-era manuals for the Elektronika BK-0010, BK-0010.01 and BK-0011M
(МС 0513), downloaded from https://gid.pdp-11.net/docstable.html on
2026-11-17 (BK-0011M) and 2026-11-18 (BK-0010 and the rest). The PDFs have
a text layer (OCR or retyped).
